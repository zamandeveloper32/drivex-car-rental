# 🚗 DriveX — Car Rental Management System

A professional PHP + MySQL Car Rental Management System created as a PHP lab assignment.

## Core Technologies

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Planned Features

- Administrator authentication
- Password hashing
- PHP sessions
- Car CRUD
- Customer CRUD
- Rental CRUD
- Search and filtering
- Pagination
- Car image uploads
- Customer document uploads
- Rental cost calculation
- Date and time processing
- Cookies
- File handling
- Rental reports
- Secure HTML output
- Input validation and regular expressions

## Local Setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project into `htdocs`.
4. Open phpMyAdmin.
5. Import `database.sql`.
6. Open `setup_admin.php` once.
7. Delete `setup_admin.php`.
8. Open `http://localhost/drivex-car-rental/`.
